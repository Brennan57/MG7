# MG7
## Devlog

The array is used to store the sparrows and their deatails indivisually. It is also used to allow the code to adjust their deatails like their "active-ness". Vectors are used to compare the distance from each indivisual sparrow and the player. They then work together within the for loop. The for loop goes through every sparrow in the array and check's their indivisual distances from the player using vectors. If one sparrow is in range, but the other isn't, the array makes it so that the one in range pups up while the other one stays hidden.
